# `/opsx:apply`

## Objetivo

Implementar el change OpenSpec activo (o el `<slug>` indicado) siguiendo **`tasks.md`**.

## Antes de codear

1. Identificá el change: **`openspec status`** o carpeta en `openspec/changes/<slug>/`.
2. Leé **`proposal.md`**, **`design.md`**, **`tasks.md`** y specs del change.
3. Leé **`openspec/project.md`** y **`docs/Integrador.txt`**.

## Ejecución

- Tarea por tarea; respetá arquitectura backend y FSD frontend (`AGENTS.md`).
- Delegá exploración pesada a subagentes si aplica.
- No commitear ni buildear salvo pedido explícito.
