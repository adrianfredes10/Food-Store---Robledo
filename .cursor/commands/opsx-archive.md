# `/opsx:archive`

## Objetivo

Cerrar un change completado y actualizar el mapa del proyecto.

## Pasos

1. Verificá que **`tasks.md`** esté completo.
2. Archivá en **`openspec/changes/archive/`** (o con CLI **`openspec archive`** si corresponde).
3. Marcá **`[x]`** en **`openspec/CHANGES_MAP.md`** (*Estado actual*; columna Skills).
4. Actualizá **`openspec/SKILLS_REGISTRY.md`** con las skills usadas en el change.
